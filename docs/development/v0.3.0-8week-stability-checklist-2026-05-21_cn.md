# v0.3.0 八周稳定性 Checklist（2026-05-21，中文）

## B. 分布覆盖（开发优先）
- [x] TF2：`nu` link 使用 `logshiftto2`，并补充构造器/链接单测。
- [x] TF2：family 调用路径统一 `nu>2` 钳制（`g_dev_inc`/`d/p/q/r`/`score`/`hessian`）。
- [x] TF2：R consistency 用例改为直接对 R `TF2`（不再借道 `TF`）。
- [x] TF2：R `TF2` 专用参数化的更多边界验收（极端参数组合、容差分层）。
  - 进展（2026-05-26）：已补充 near-boundary 本地验收（`p/q` 的 `lower_tail` 与 `log_p` 语义、`score/hessian` 在 `nu<2` 输入下的有限值稳定性）。
  - 进展（2026-05-26）：`TF2.q` 增加一次 Newton 风格修正，以改善 `q(p(x))` 反演一致性（近边界场景）。
  - 进展（2026-05-26）：R consistency 已引入分场景容差分层（central/tail/ultra_tail_prob 的 d/p/q 使用分级 rtol/atol），为后续 TF2 专用参数化验收提供更细粒度门禁。
  - 进展（2026-05-26）：`TF2.q` 的 Newton 修正已增加概率裁剪、导数有限值防护与步长裁剪，降低极端尾部场景的数值震荡风险。
  - 进展（2026-05-26）：修正 `TF2.q` 细节以显式遵循 `lower_tail` 语义（Newton 校正中的参考概率改为同 tail 定义），并补 upper-tail 反演测试。
  - 进展（2026-05-26）：`TF2.q` 新增 non-finite 回退防护（step/q 非有限值时回落到保守路径），并补极端 `log_p` 场景稳定性测试。
  - 进展（2026-05-26）：`TF2.q` 在边界概率点(≈0/1) 禁用 Newton 更新，避免 staged kernel 在极端尾部的过修正。
  - 进展（2026-05-26）：新增 `q` 单调性网格验收（0.01~0.99）以贴近 GAMLSS 分位函数基本行为约束。
  - 进展（2026-05-26）：R 侧补充 `lower.tail=False` 语义对齐验收（`p/q` 双路径）。
  - 进展（2026-05-26）：R 侧补充 `log.p` 语义对齐验收（含 `lower.tail=False` 组合路径）。
  - 进展（2026-05-26）：补充 `p` 的 lower/upper tail 互补关系验收（Python 与 R 双侧分别断言 `p_lower + p_upper = 1`）。
  - 进展（2026-05-26）：补充 `q` 的 `log.p` 路径对齐验收（含 `lower.tail=False` 组合路径）。
  - 进展（2026-05-26）：补充分档参数剖面的 `q→p` 回投影验收（Python 与 R 双侧），用于约束分位路径闭环误差。
  - 进展（2026-05-26）：`TF2.q` 对 `log.p` 输入先裁剪到 `<=0` 再指数化，避免异常输入导致概率上溢。
  - 进展（2026-05-26）：R consistency 参数网格已收敛到 TF2 语义域（`nu>2`），避免域外点混入对齐结论。
  - 进展（2026-05-26）：`TF2.q` 在向量化概率网格路径启用弱单调修正（按 p 排序后 cumulative max），降低 staged 数值导致的局部反序风险。
  - 进展（2026-05-26）：弱单调修正仅在输入概率网格本身单调时启用，避免非单调输入场景被跨点耦合改写。
  - 进展（2026-05-26）：新增非单调概率输入的点态一致性验收（向量调用与逐点调用结果一致），约束 `TF2.q` 不发生跨点耦合改写。
  - 进展（2026-05-26）：新增 near-`nu=2` 边界剖面（`nu∈[2.000001,2.08]`）的 R d/p/q 一致性验收，补强 TF2 语义边界证据。
  - 进展（2026-05-26）：补充 near-`nu=2` 场景下 `upper-tail + log.p` 的 `q→p` 回投影验收（Python/R 双侧）。
  - 进展（2026-05-27）：`TF2.q` 对非法概率输入增加显式防护（`p` 路径要求 `0<=p<=1`、`log.p` 路径要求 `p<=0`），非法输入返回 `NaN`，避免被内部裁剪“静默纠正”后掩盖语义错误；并补对应构造器单测。
  - 进展（2026-05-27）：修正 `log.p` 边界语义：`TF2.q(log.p=True)` 接受 `-Inf` 作为合法边界输入（对应概率 0），避免将其误判为非法并返回 `NaN`；补充 `lower.tail` 双路径边界测试。
  - 进展（2026-05-27）：`TF2.q` 对非法输入先映射到保守内部概率再执行 staged kernel，最终再按合法性掩码返回（非法输入仍为 `NaN`），降低非法值直接参与 Newton/尾部路径造成的数值污染风险；并将 `log.p=-Inf, lower.tail=False` 断言细化为 `+Inf` 边界语义。
  - 进展（2026-05-27）：`TF2.q` 的保守内部概率填充值改为显式表达（`log(0.5)` / `0.5`，去除魔法常数），并新增“混合合法/非法输入”向量化验收，确保合法点保持有限值、非法点稳定回传 `NaN`。
  - 进展（2026-05-27）：`TF2.q` 的保守填充值进一步改为与输入同形状的数组填充（`full_like`），补充 `log.p` 混合合法/非法向量输入在 `lower.tail=False` 路径的点态掩码验收（合法点保留、`+0/NaN` 非法点回传 `NaN`、`-Inf` 边界保持 `+Inf`）。
  - 进展（2026-05-27）：`TF2.q` 的 safe-fill 构造改为按 `log.p`/普通概率路径分支生成（避免构造未使用张量），并补充二维输入形状保持与点态掩码验收，确保向量化/广播场景下非法输入隔离行为稳定。
  - 进展（2026-05-27）：`TF2.q` 的 `log(0.5)` 保守填充值改为 `-log(2)` 显式常量表达（同 dtype），并补充 `log.p=+Inf` 非法输入的点态掩码验收，确认仅非法点回传 `NaN`。
  - 进展（2026-05-27）：`TF2.q` 的 `log.p` 路径显式拆分为“内部数值钳制”和“输出合法性掩码”两层语义（`<=0` 参与内部计算、非法点最终仍回传 `NaN`），并补 `log.p=0` 边界分位（`+Inf`）验收。
  - 进展（2026-05-27）：补充 `log.p=0` 在 `lower.tail=False` 路径的边界验收：在当前 `eps` 裁剪语义下断言其为“有限且更靠左”的近边界分位（而非数学极限 `-Inf`），并与既有 `lower.tail=True` 的 `+Inf` 验收形成双向边界覆盖。
  - 进展（2026-05-27）：`TF2.q` 对合法 `log.p=0` 增加返回层边界恢复（`lower.tail=True -> +Inf`, `lower.tail=False -> -Inf`），在保留内部 `eps` 裁剪稳健性的同时恢复分位函数的极限语义。
  - 进展（2026-05-27）：`TF2.q` 进一步恢复合法 `log.p=-Inf` 的返回层极限语义（`lower.tail=True -> -Inf`, `lower.tail=False -> +Inf`），避免边界点被内部裁剪路径回落为有限近似值。
