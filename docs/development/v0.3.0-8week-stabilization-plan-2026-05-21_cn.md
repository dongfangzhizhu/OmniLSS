# OmniLSS v0.3.0 8 周稳定化开发计划（执行版）

> 版本：v1.0  
> 日期：2026-05-21  
> 目标：消除 Critical/High 技术债、完成 CG_FULL、冻结基准并发布 v0.3.0。

## 架构决策（ADR）

1. **RS 内循环固定 max_inner=1**：对齐 R `gamlss::glim.fit`，避免 warm-start 附近振荡。  
2. **NumPy 默认后端**：`n < 50k` 默认 NumPy；JAX 仅大样本且显式需求。  
3. **CG_FULL 使用 RS warm-start**：先运行 2 轮 RS 建立初值。  
4. **eta 截断按 link 动态策略**：identity 使用宽区间，log/logit 使用紧区间。

## 周计划（摘要）

- **Week 1**：并发安全、梯度监控、max_inner 一致性、eta/working response 稳定性。  
- **Week 2**：相对收敛判据、CG 标签诚实化、API token 认证。  
- **Week 3-4**：交叉导数、联合 Fisher、CG_FULL 全实现与集成。  
- **Week 5-6**：R golden files、性能快照冻结、后端路由与 WLS 优化。  
- **Week 7-8**：测试强化、CHANGELOG、发布检查、论文更新。
