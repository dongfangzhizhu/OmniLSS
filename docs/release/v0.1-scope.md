# OmniLSS v0.1.0 发布范围（Scope Freeze）

> 本文件是 v0.1.0 产品里程碑的功能边界与唯一真相源（对应执行计划 E01 / Task 1.1）。
> 代码库当前开发版本为 `0.4.0`；正式发版时由 E13 统一 `pyproject.toml`、`_version.py`
> 与 `CHANGELOG`，本文件不预先改动版本号。

## 1. 产品定位

Python Distributional Regression Framework：预测完整条件分布，对 `mu` / `sigma` / `nu` / `tau`
分别建模，支持线性项、`pb()` P-spline 平滑项与简单随机截距，提供参数估计与标准误、分位数预测、
残差诊断，以及可与 R `gamlss` 对照的统计量。

## 2. 支持范围（v0.1.0 承诺）

| 能力 | 承诺 |
|---|---|
| 分布族 | 15 个白名单族（11 个 P0 + 4 个 P1），见 `v0.1-supported-features.md` |
| 参数体系 | `mu` / `sigma` / `nu` / `tau`，参数可固定（`*.fix`） |
| 默认算法 | RS（Rigby–Stasinopoulos），唯一生产级默认 |
| 平滑项 | `pb()` 单变量 P-spline，含 `edf` 计算 |
| 建模入口 | 多参数 `gamlss(formula=..., sigma_formula=...)` + `GAMLSSRegressor` |
| 统计量 | 系数、标准误、Global Deviance、AIC、GAIC、EDF |
| 预测 | `predict_params` / `predict_mean` / `predict_quantiles` / `predict_distribution` |
| 诊断 | Quantile Residuals（离散族固定 seed 随机化）、Q-Q、Worm Plot、ACF、PIT |
| 持久化 | `model.save()` / `GAMLSSModel.load()`，ZIP + JSON + `allow_pickle=False` npz |
| 平台 | Linux CPU、Windows CPU（Python 3.10–3.12） |

## 3. 明确不做（P2 冻结）

- 不新增低频分布族，不扩张 R Symbol 覆盖率；
- 不改动 `omnilss-pro/`、`omnilss-server/`、`api/grpc/`、`api/http/`、`multivariate/`、
  `online/`、`automl/`；
- 不重写 `rs_algorithm.py` 架构，不合并 `smooth/` 与 `smoothers/`；
- GPU 不作为发布阻塞项，仅保留实验接口；
- 不做 R `gamlss` 全量替代、企业级模型服务平台、大型 AutoML。

## 4. 数值安全红线（fail-closed）

1. 拟合与矩阵求解路径禁止用 `nan_to_num` 等静默掩盖 `NaN` / `Inf`；
2. 非有限 Hessian 必须由 `HessianStabilizationResult.is_finite=False` 上报，
   并最终体现为 `termination_reason == "non_finite_deviance"`，不得计为收敛；
3. Link 函数在 `eta = ±1000` 时输出必须有限；
4. `NO` 在 `sigma = 0` 时一阶/二阶导数必须有限（支撑集边界钳制，不产生 `inf - inf`）。
