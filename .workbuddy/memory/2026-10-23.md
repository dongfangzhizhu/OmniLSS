## D2.54：dpqr 失败族首批——MN3/MN4/MN5 支持域探测修复 + ZABB/ZIBB bd 契约

- **六个族的 dpqr fail / rsdev skip 全是探测网格溢出支持域**，不是实现缺陷（但 ZABB/ZIBB 的族元数据确是真缺陷，见下）。

- **MN3/MN4/MN5（1..k 分类族）**：R 的 dMN3 对 x∉[1,3] 直接 `stop()`（"x must be 1, 2 or 3"），通用离散候选（0..7、1..8、连续）都在域外 → R 侧无法求值，报出的 failure 是探测缺陷；拟合样本也按 0..7 抽 → R fit 报 "response variable out of range"。修法：scanner 加 `_SUPPORT_BOUNDS` 表，这三族用**支持域本身**当探测网格，**平铺到 n 长度**（两侧都验证过：不平铺时我们广播报错、R 回收成 NA 报 "missing value where TRUE/FALSE needed"），`ok` 判据改为"每个支持点密度有限为正"（MN3 支持仅 3 点，够不到通用 n-1 阈值）。
- **ZABB/ZIBB（0..bd beta-binomial）**：族对象没声明 `bd` 为固定参数 → 扫描器不传 bd，R 落回默认 bd=1 → "x must be <= the binomial denominator 1"；拟合样本 0..7 也让 R 报 "y values must be 0 <= y <= 1"。且内核拒绝探测携带的 float/向量 bd（`dZABB` 的 `_check_bd` 要求单个静态 int——它按 bd 建内部网格）。修法：两族加 `fixed_parameters=("bd",)`（BI 已有的形状），d/p/q 用 `_static_bd` 把**常量向量折叠成静态 int**（非常量拒绝），拟合走 cbind(y, fail)。
- **连带回归（已修）**：`fixed_parameters` 生效后 deriv 闸把 `bd=10` 传给分数函数，而 AD 分数把 bd 烘焙在闭包里、不接受该关键字 → ZABB/ZIBB deriv pass→fail。修法：`gate_derivatives` 加 `call()` 回退（带 extra 调用失败则不带 extra 重试），与 `_python_dpqr` 已有的回退模式一致。
- **实测**：MN3 dpqr/rsdev 102.909 vs R 102.909、MN4 127.737 vs 127.738、MN5 153.062 vs 153.062；ZABB 208.312 vs 208.313、ZIBB 209.81 vs 209.811；六族 deriv/dpqr/rsdev 全 pass。
- 新测试 `tests/test_support_bounded_dpqr.py`（8 例）：校准网格在支持域内、拟合样本在域内且整数、d/p/q 对活 R 逐值（含 R ifelse 回落：`[1,k]` 内非 1..k-1 的值携带参考类质量）、bd 为固定参数、常量向量 bd 接受/非常量拒绝、带 bd 的 d/p 对活 R。
- **教训**：探测网格必须落在族自己的支持域内（D2.28 的又一形态）；声明 `fixed_parameters` 会改变探测载荷形状，必须同步检查 deriv 闸的调用约定。

## D2.55：BE* 四族 dpqr/rsdev 修复——[0,1] 支撑族的边界路由与探测网格

- **三个叠加缺陷**：①密度边界路由用 `y<=0 / y>=1` 而非精确相等，R 是精确相等分流并在域外清零（且每族规则不同：BEINF 两端原子、BEINF0 只 0 原子且 x>=1 为 0、BEINF1 只 1 原子且 x<=0 为 0、BEZI x>=1 为 0、BEOI x<=0 为 0）——旧路由让 x>1 落进原子（dBEINF(2)=tau/(1+nu+tau)、dBEZI(2.41)=3121.8、dBEINF0(1)=1.7e+11）；②通用探测网格 0..7 溢出 [0,1] 且我们宽松的密度在域外返回有限值，每个域外点都被计为"好点"；③`_fit_data` 给所有 Mixed 族注 30% 的 0，但 BEINF1/BEOI 支撑是 (0,1] 无 0 原子 → R fit 报 "response variable out of range"。
- **两套平行实现都要修**：distributions_b4.py 的 `_be*_log_pdf`（AD 拟合路径）与 dpqr_functions.py 的 `_beinf_logpdf`（fam.d 路径，之前用 eps 阈值）——只修前者时 dpqr 闸因新网格只在 [0,1] 内比较而"看起来"通过，测试在域外才暴露。这是 D2.41「平行实现收成同一实现」教训的又一实例。
- scanner 加 `_UNIT_SUPPORT`（五族固定 `linspace(0,1,n)`，不走评分——内部网格得分更高会静默丢掉原子）与 `_UNIT_ATOMS`（原子位置表，驱动拟合样本注入）。
- 结果：BEINF/BEINF1/BEOI/BEZI 的 dpqr fail→pass、rsdev skip→pass（8 闸）；BEINF0 保持 pass。rsdev 数字：BEINF 50.8072、BEINF0 61.7269、BEINF1 63.3348、BEZI 63.6041、BEOI 53.7977，全部与 R 逐位一致。
- 新测试 `tests/test_unit_interval_inflated.py`（5 例）。

## D2.57：GU/RG 的 p/q 互换、ST3C 的 tau 下限、数值 CDF 的积分窗口——dpqr 失败清零

- **GU/RG 的 CDF 与分位数互换**：密度本来正确（dGU 最小 Gumbel、dRG 最大 Gumbel），但 pGU 用了最大 Gumbel 公式、pRG 用了最小，q 随之；pRG 还把 z 写成 (mu-q)/sigma。活 R 数值：pGU(0.3,0.5,0.5)=0.4884552=1-exp(-exp(z))、pRG=0.2249618=exp(-exp(-z))。qGU=mu+sigma*log(-log(1-p))、qRG=mu-sigma*log(-log(p))（R 的 qRG 在 p==0 给 0 是 quirk，我们给 -Inf 并登记）。
- **ST3C 的 tau 下限**：CDF/q 把 tau 钳在 1.0，但 R 支持 df<1（pST3C(-1,nu=.5,tau=.5)=0.6058544583）。去掉下限后四个参数角与 R 一致到 1e-11。
- **共享数值 CDF 的积分窗口**（GT/SHASH 共用）：有限窗口 mu±(8*max(|σ|,1)+8) 再归一化，对 GT 重尾（nu=tau=0.5 时密度按 |z|^-1 衰减）丢掉 5.34% 质量。改为从 -Inf 积分（同 R 的 pGT）；SHASH 实测不受影响。
- **扫描器口径**：R 侧自身数值失败（GT 的 qGT: "roundoff error is detected in the extrapolation table"）记为"无 R 参照"而非族缺陷——"R 答错"与"R 答不出"是两回事。
- 结果：GU/RG/GT/ST3C dpqr fail→pass，**dpqr 闸 146 族 0 fail**（111 pass / 35 skip）。新测试 `tests/test_gumbel_st3c_numeric_cdf.py`（11 例）。

## D2.58：R 桥的 warning 口径 + BCTO tau 容忍 + BB 缺口登记

- **R 桥把 fit 期间的任何 warning 当错误**（r_parity_batch.R 的 `tryCatch(warning=...)`）——而 R 对"RS 未收敛"正是发 warning（BCTO 撞周期预算即触发），于是该族 rsdev 永远是 skip。改为 `withCallingHandlers` 记录告警并继续，结果里带 `warnings` 字段；BCTO 的 rsdev 因此可测（R 未收敛 → warn，与 ZIPIG/ZINBI/PE2 同类）。
- **BCTO 的 tau deriv**：BCTO 是 BCTo 的重命名克隆（R 安装版 6.1.1 没有 BCTO），其 tau 分数转录自 R 的 BCT dldt（0.01 前向差），而闸的中央差看真导数 → 2.689e-03。按 BCT 已有的登记（1e-2 + note）为 BCTO 补同款条目，并记录实测证据。
- **BB 缺口（未修，记录）**：BB 的 `parameters=("mu","sigma","bd")` 把固定参数 bd 同时放进参数列表，扫描器既为 bd 造网格又额外传 bd → `dBB() got multiple values`。改成 BI 的形状（bd 只在 fixed）会让 AD 路径缺 bd（`_bb_log_pdf(y,mu,sigma,bd)` 无默认）。因 BB 的 rsdev 已 pass、且修复会牵动拟合路径，本轮不动；BB 的 deriv/dpqr 仍是 skip（未测量，非失败）。修复方向：`_bb_log_pdf` 给 bd 默认值 + `fixed_parameter_defaults={"bd": 10.0}`，并让拟合把数据里的 bd 透传到 AD 密度（同 NET 的固定参数模式）。
- **NET 的两项 skip 是正当的**：NET 是自有族（R 无对应），deriv 的 skip 源于固定参数 nu/tau 被当成自由参数造网格导致密度无效——同样留待统一处理固定参数网格。

## D2.59：初值三缺陷的第二/第三簇——LNO/LOGNO/LOGNO2、SEP/SN2/EGB2、BNB/ZABNB/ZIBNB

**根因（与 D2.53 SI 完全同款）**：`_initial_sigma` 对逐点 mu 目标求残差尺度，残差恒 0 → sigma 起在 eps 地板。实测 11 个族全部 sigma0=2.2e-16。R 的初值式全部是**固定尺度**，与 mu 目标无关。

- **簇 1（LNO/LOGNO/LOGNO2）**：R 的 mu.initial=(log(y)+mean(log(y)))/2、sigma.initial=sd(log(y))（n-1）。我们逐点 log(y) + 残差尺度 → sigma=eps。LNO 因此 1e13、LOGNO2 也 eps 起步。
- **簇 2（SEP/SEP1/SEP2/SN2/EGB2）**：R 的 mu.initial=(y+mean(y))/2；sigma=sd(y)/4（SEP 三兄弟）/sd(y)（SN2）/0.1（EGB2）；nu=0.1、tau=1.6（SEP 三兄弟）。我们 mu=y、sigma=eps、nu=1.0、tau=1.0。
- **簇 3（BNB/ZABNB/ZIBNB）**：R 的 mu=(y+mean(y))/2、sigma=max((var(y)-mean(y))/mean(y)^2, 0.1)（n-1 var）、nu=0.1、tau=零比例（ZABNB）/0.1（ZIBNB）。我们 sigma=0.0。

**修后结果（全族流扫描前单族验证）**：
- LNO fail→pass（137.87 vs R 137.87）；LOGNO/LOGNO2 保持 pass
- SEP2/SN2/EGB2 fail→warn（R 未收敛，我们 132.017/132.139/131.936）
- BNB fail→warn（py 198.741 vs R 198.699）
- ZABNB fail 23.7%→4.3%、ZIBNB fail 27.6%→10.9%（仍差，见下）

## D2.60：JSUO rsdev 修复——初值 + R 的 IRLS Hessian 形式（1613.89 → 146.84，闸转 pass）

**两个叠加缺陷**（与 D2.53 SI / D2.59 簇同源但多一层）：

1. **初值全缺失**：registry key 是 JSUO，但族对象 .name 是 "JSUo"（distributions_b14 的 build_ad_family(name="JSUo")，o_alias_compat 的 _clone 也传 "JSUo"）——_fitting_init.py 无任何条目，四参数全走 generic fallback（mu target=y、sigma=残差 eps 地板、nu=1.0、tau=1.0）。基线拟合 mu=[1.9e7, 0.80]、sigma=e^15.06 完全发散，deviance 1613.89 vs R 146.78（rel 10 倍）。活 R dump：mu.initial=(y+mean(y))/2、sigma.initial=0.1、nu.initial=0、tau.initial=0.5；links mu=identity/sigma=log/nu=identity/tau=log（与我们一致）。
2. **Hessian 形式不符**（关键新发现）：build_ad_family 喂 IRLS 的是 log 密度的**真二阶导**，而活 R 的 JSUo() 对四个参数都喂观测信息近似 d2ldX2 = -dldX²（族函数内 ifelse 下限 -1e-15，我们管道的 compute_working_weights_and_response 有同样的下限）。score 两侧都是真导（deriv 闸本就 pass），**只有 Hessian 形式差**——而 IRLS 步长完全由 Hessian 构建。证据：只补初值时第一周期 mu=[3.41, -0.51] vs R [1.84, +0.36]（斜率反号），20 周期 147.365 vs R 146.778（rel 4e-3 仍 fail）。

**修法**：_fitting_init.py 补四个 JSUo 分支（注意 .name 大小写）；distributions_b14.py 加 _JSUO_SCORES/_JSUO_HESSIANS（R 闭式转录，SHASHo2 D2.40 同款 override 模式），JSUo() 接 score_overrides/hessian_overrides。_clone 会复制 score_functions/hessian_functions，别名 JSUO 自动继承。

**结果**：20 周期 146.8435 vs R 146.7781（rel 4.5e-4，闸 pass）；系数 mu=[1.299, 0.083] vs R [1.306, 0.080]、sigma=0.550 vs 0.572、nu=-0.820 vs -0.814、tau=0.633 vs 0.656。双方都未收敛（仍在降），轨迹形状一致（R：168.85→146.78 单调）。deriv 闸仍 pass（override 的 score 正是被检对象——转录正确性的守门人）。新测试 omnilss/tests/test_jsuo_fit_parity.py（8 例：初值对活 R 求值、score 对 R 的 dldm/dldd/dldv/dldt、hessian=-score² 形式、score 与密度中心差自洽、拟合 parity、不发散）。

**遗留线索**：JSU（非 o）与 SHASH/SHASHO 的 R d2ld*2 槽更复杂（非简单 -score²），未查是否同型缺陷——SHASH/SHASHO 的 1-2e-3 残留差距是候选。ZABNB/ZIBNB 的诊断结论（R 自身振荡 + sigma 撞 eps 地板）已登记在上一节。

## D2.61：SEP1 从"无法拟合"到 parity pass——R 闭式 score/hessian override

**问题**：SEP1 的 rsdev 闸在**每个样本**上报 "python raised NotImplementedError: Differentiation rule for 'igamma_grad_a' not implemented"——族完全无法拟合。deriv 闸却 pass，这是关键线索：SEP1 密度走 gammainc(1/tau, s)，JAX 能求一阶导（d/da 由 igamma_grad_a 承担），但二阶导再进 igamma_grad_a 没有规则 → **拟合需要的 Hessian 建不出来**。与 build_ad_family docstring 里 BCT/BCPE 的既有记录完全同型。

**修法**（D2.40 SHASHo2 / D2.60 JSUO 同款）：转写活 R 的 SEP1() 槽位——
- dldm/dldd/dldv：闭式（由 lpdf、lcdf、pgamma 组合）
- dldt：解析 dldf + CDF 部分的双侧差分（t1=tau+2e-5、t2=tau-2e-5）——R 自己也对 pgamma(s,1/tau) 求不了 tau 导数，parity 就是用 R 的差分而不是更好的导数
- d2ldX2 = -dldX²（GN 形式）
接进 SEP1() 的 score_overrides/hessian_overrides，整族脱离 AD 路径。b15 模块级补 gammainc 导入（原来只在密度函数内局部导入）。

**结果**：全族流样本 20 周期 **124.842834 vs R 124.842999（rel 1.3e-6）**，系数 mu=[2.11014, 0.08969] vs R [2.10954, 0.09048]、sigma=0.403384 vs 0.403319、nu=-0.235024 vs -0.236274、tau=2.743305 vs 2.743568；双方 converged=False（R 报 "Algorithm RS has not yet converged"）。deriv 闸 pass。

**deriv 闸的 tau 容差登记**（1e-2 + note）：R 的 dldt 把 CDF 项写成 log(1+pgamma(s,1/tau))，**漏了真实 lcdf 的 sign(w)**；实测 R 自己的 dldt 对 R 自己 dSEP1 的中心差（h=1e-6）在 5 个探针点上 rel = 8.1e-11/1.1e-10/4.4e-11/**5.7e-1**/1.1e-10——第四个点 (y=4,mu=2,sigma=0.5,nu=-1,tau=1.5) 深负尾 R 自己差 57%。我们照抄 R 的公式，闸在标定网格上看到 1.489e-3。修导数会离 R 更远（D2.15）。（顺带记录：dldv = exp(lpdf-lcdf)*(w/nu) 在 nu 恰为 0 且 w=0 时是 0/0=NaN，R 与我们同为 NaN；拟合从 nu=0.1 起步不会触到。）

**新测试** omnilss/tests/test_sep1_fit_parity.py（6 例）：不再抛 NotImplementedError、hessian=-score²、四个 score 对 R 的 dldm/dldd/dldv/dldt、mu/sigma/nu 与密度中心差自洽、拟合 parity、系数贴合 R。
