## D2.225 / P0-3：MIXED 语义对齐（发布门禁收尾之三）

**根因重新定位（backlog 描述已过时，同 P0-1）**：DEVELOPMENT_PLAN 要求
「实现 `RS(n1)→CG(n2)` 兼容模式，或改名并隔离实验路由」——但 `mixed_fit`
（`omnilss/algorithms/mixed_algorithm.py`）早已实现 R-compatible
`RS(n1)→CG(n2)`，`fitting.py:1833` 也早已让 `method="MIXED"` 提前 return
`mixed_fit`。真正缺的是 P0-3 验收标准里那句「**与 R `mixed` 数值/语义对照通过**」：
既有 `test_mixed_rs_cg.py` 只验内部自洽（我们自己的 RS→CG pipeline），
从无活 R 对照。另外残留一套矛盾语义：`_fitting_utils._apply_method_step`
的 `MIXED → 0.75 damped RS` 分支 + `fitting.py` 包装 docstring 的
「75% step (damped RS, experimental)」——`MIXED` 走 `mixed_fit` 提前 return，
内联 IRLS 循环永不以 MIXED 执行，该分支是**死代码**且与出货行为矛盾。

**R 侧关键事实**：`mixed()` 不是导出函数，是 `gamlss()` 内部的局部函数
（`R/gamlss/R/gamlss-5.R:163`）：
`mixed <- function(n1=1,n2=20){ RS(n.cyc=n1); CG(n.cyc=n2) }`。
`gamlss()` 用 `substitute(method)` 对 `c("RS()","CG()","mixed()")` 做 pmatch，
因此活 R 探针必须传**字面** `method=mixed(1,4)`（不能用 `eval(m)` 变量）。
实测 R 4.6.0 / gamlss 5.5.0 / gamlss.dist 6.1.1 / set.seed(1) 的 80 点样本：
`mixed(1,4)/(2,3)/(1,0)` 的 mu/sigma 系数与 deviance 全部落表。

## D2.231 / ZABI 收敛探测：R 侧向量化缺陷 + bd kwarg 静默忽略修复

**目标**：冻结清单里 ZABI 是 pending（备注「需 binomial 两列/bd 负载」）。探测结论：
**不能晋级**（R 侧缺陷），但顺带发现并修复了一个真实 API bug。

**发现 1（产品缺陷，已修）**：`gamlss(..., bd=10)` **kwarg 被静默忽略**。
它落进 `**optimizer_kwargs`，而 `_resolve_fixed_parameter_values` 只看 data 列 /
constructor / `fixed_parameter_defaults`（ZABI 的默认是 `bd=1.0`）→ 拟合用 bd=1，
所有 y>1 观测密度为 0 → **deviance=inf**，mu 漂到边界（系数 15）。把 `bd` 作为
**data 列**传入则正常（dev 469.22）。修法：family 解析后，把名称命中
`family.fixed_parameters` 的 kwarg 并入复制后的 data。修后 kwarg 与 data 列**逐位一致**
（dev 469.2173、系数相同、收敛）。测试
`test_binomial_zero_variants_bd.py::TestFit::test_bd_keyword_is_forwarded_like_a_data_column`。

**发现 2（R 侧缺陷，ZABI 不能作 golden）**：即便 bd=10 正确，我们收敛解
（dev 469.2173，mu [0.2316,0.5414]）与 R（dev 469.4568，mu [0.23252,0.53496]，
mu 系数差 6.4e-3）不同。根因在 R：
- R 的向量化 `dZABI` 用 `dBI(0, bd[x!=0], mu[x!=0])` 算 hurdle 归一化项，而 `x` 是**标量 0**；
- R 的 `dBI` 末尾 `ifelse(x < 0, 0, fy)` 在 x 标量、fy 向量时**返回长度 1**（R 的 ifelse 取 test 长度），
  于是把**第 1 个观测**的 `(1-f0)` 循环给所有正观测；
- 标量 `dZABI` 正确且与我们的逐位一致（mu=0.2644/sigma=0.2167 处：R 标量 0.2215466 = 我们；
