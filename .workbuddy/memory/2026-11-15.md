## D2.225 / P0-3：MIXED 语义对齐（发布门禁收尾之三）

**根因重新定位（backlog 描述已过时，同 P0-1）**：DEVELOPMENT_PLAN 要求
「实现 `RS(n1)→CG(n2)` 兼容模式，或改名并隔离实验路由」——但 `mixed_fit`
（`omnilss/algorithms/mixed_algorithm.py`）早已实现 R-compatible
`RS(n1)→CG(n2)`，`fitting.py:1833` 也早已让 `method="MIXED"` 提前 return
`mixed_fit`。真正缺的是 P0-3 验收标准里那句「**与 R `mixed` 数值/语义对照通过**」：
既有 `test_mixed_rs_cg.py` 只验内部自洽（我们自己的 RS→CG pipeline），
从无活 R 对照。另外残留一套矛盾语义：`_fitting_utils._apply_method_step`
的 `MIXED → 0.75 damped RS` 分支 + `fitting.py` 包装 docstring 的
「75% step (damped RS, experimental)」——`MIXED` 走 `mixed_fit` 提前 return，
内联 IRLS 循环永不以 MIXED 执行，该分支是**死代码**且与出货行为矛盾。

**R 侧关键事实**：`mixed()` 不是导出函数，是 `gamlss()` 内部的局部函数
（`R/gamlss/R/gamlss-5.R:163`）：
`mixed <- function(n1=1,n2=20){ RS(n.cyc=n1); CG(n.cyc=n2) }`。
`gamlss()` 用 `substitute(method)` 对 `c("RS()","CG()","mixed()")` 做 pmatch，
因此活 R 探针必须传**字面** `method=mixed(1,4)`（不能用 `eval(m)` 变量）。
实测 R 4.6.0 / gamlss 5.5.0 / gamlss.dist 6.1.1 / set.seed(1) 的 80 点样本：
`mixed(1,4)/(2,3)/(1,0)` 的 mu/sigma 系数与 deviance 全部落表。
