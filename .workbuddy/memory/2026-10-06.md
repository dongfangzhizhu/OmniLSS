## D2.8 LOGNO 参数化错位修复（commit 7aaea8a）

**现象**：`g_dev = 8.9e12`，R 是 `173.05`，且报 `converged=True`
（`relative_deviance_converged`）—— 又一次"发散静默报告为成功"。

**缺陷一（根因）：d/p/q/r 四个函数的 mu 参数化错位。**
R 有两个对数正态族，mu 语义不同：
- `LOGNO` = `dlnorm(meanlog = mu)` → mu 是 **log(Y) 的均值**
- `LOGNO2` 内部用 `mean = log(mu)` → mu 是 **中位数**

Python 四个函数全用了 `log(mu)` （= R 的 LOGNO2）。活 R 判决性证据：
```
dLOGNO (c(2.1509,2.3591), mu=0.8, sigma=0.4) -> 0.46200903 0.41830590
dLOGNO2(c(2.1509,2.3591), mu=0.8, sigma=0.4) -> 0.02181086 0.01093765
Python 修复前                                 -> 0.021811  0.010938
```

**缺陷二：RS 用观测 Hessian 而非期望 Hessian。**
R 声明 `d2ldd2 = function(sigma) -2/sigma^2` —— **签名只接受 sigma**，
只有对 y 取期望才可能 ⇒ RS 用 Fisher scoring。Python 用观测 Hessian
`1/σ² - 3(log y - μ)²/σ⁴`，当 `(log y - μ)² < σ²/3` 时变**正** → 工作权重失效
→ sigma 崩到 1e-18。改为 `-2/σ²`。

**效果**：Python `173.05494254762493` vs R `173.05494254762488`（差 5e-14），
mu 系数逐位一致。

**四条方法论（重要）**：
1. 收敛 ≠ parity —— `converged=True` 又一次掩盖了 8.9e12 的解。
2. 导数对不上时用**有限差分**定位，别读代码猜。
3. R 导数函数的**签名**暴露语义：`function(sigma)` 不含 y ⇒ 期望 Hessian。
4. 同族有多个参数化变体（LOGNO vs LOGNO2）时，**必须以活 R 数值判定归属**，
   不能看名字想当然。

## D2.10：BI 二项响应被 bd 二次缩放

扫描器报 BI/DBI `max rel diff 1.35e16`，根因不在导数。

R 侧判决性证据：`gamlss()` 对二项族接受**两列矩阵** `cbind(成功,失败)`，
`y` = 成功**计数**、`bd` = 总数；`dBI` 函数体就是 `dbinom(x, size=bd, prob=mu)`；
`BI()$dldm = (y-bd*mu)/(mu(1-mu))` 只有 y 是计数才量纲自洽。

Python 在 `dBI`/`g_dev_inc`/`dldm` 三处都写了 `y_counts = round(y*bd)`
——**分母乘了两遍**。`pBI`/`qBI`/`rBI` 另有：逐元素 zip 在 bd 为标量时崩、
长度不同不做 R 式循环补齐、`rBI` 没有 `bd` 参数。

**为什么长期没发现**：`test_r_consistency_bi.py` 全部用 `bd=1`（Bernoulli），
而 `bd=1` 时 `round(y*1)=y`，缺陷完全不可见。

**新认知**：deriv 关对这类缺陷是**盲的** —— FD 与解析导数跑同一个错误变换，
自洽但全错。只有活 R 的**数值**能戳穿。

## D2.12：BCT 拟合路径漏掉截断项（真缺陷）

`distributions.BCT` 的 `_log_density`（喂 `g_dev_inc` 与数值 score/Hessian）
**漏了** R `dBCT` 与我们 `dpqr_functions.dBCT` 都有的截断项
`- log(pt(1/(sigma*|nu|), df=tau))`。

- 实测 `max|log d - (-g_dev_inc/2)| = 0.2199204`（常数）=
  `log(1/pt(0.952, df=4))`。
- **常数偏移看着无害，但该项依赖 sigma 与 nu → 每个 score/Hessian 都错**。
  而 `mu` 恰好不受影响（与参数无关的常数求导即消）——
  **"只有部分参数对得上"就是线索**。
- 修法：JAX **没有 Student-t CDF**（只有 `t.pdf`/`t.logpdf`），
  用 `pt = 1 - 0.5*I_{df/(df+t^2)}(df/2, 1/2)`（`BCTo._bcto_log_pdf`
  已在用），`|nu|` 取下界避免 `1/|nu|` 溢出毁梯度。

## 新发现：Box-Cox 族 mu link 整簇互换（未修，已登记）

R vs 我们：BCT/BCCG/BCPE 的 `mu.link` 应为 `identity`（我们是 `log`），
BCTo/BCPEo 应为 `log`（我们是 `identity`）—— **`o` 后缀与截断变体正好互换**。
`BCTUNTR`/`BCCGUNTR`/`BCPEUNTR`/`BCTO` 在 R 里不存在，对应 BCTo/BCCGo/BCPEo。

**试过改 BCT 的 mu link → identity，拟合直接发散**（mu ~ -1.5e7，
`non_finite_deviance`）。根因是我们的 BCT 用**数值** score/Hessian，
R 用闭式（`d2ldd2 = -2*tau/(sigma^2*(tau+3))`）。**换 link 只改优化几何、
不改最优解**，所以先还原为 `log`。下一项 = 移植 R 的解析导数。
