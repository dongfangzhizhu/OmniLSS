## D1-E 批次四：exGAUS p/q/r + EGB2 纠错（commit 1618615）

- **EGB2 参数化纠错**：Python 原把 R 公式套在 `log(y)` 上（R 用原始 `x`），
  且 `mu.link` 写成 log（R 是 identity，mu 是位置参数）。两者都改。
- exGAUS 密度原本就对，补齐 p/q/r：`q` 用向量化二分（R 用 `uniroot`，
  tol = double.eps^0.25 ≈ 1.2e-4，是 **x 尺度绝对容差**，对 R 比较按此放宽，
  自洽性 `p∘q=id` 另用紧容差）；`r` 用 `N(mu,sigma)+Exp(mean=nu)` 卷积抽样。
- EGB2 的 p/q 走 F 分布（scipy `f.cdf/ppf`），与 R 的 `pf/qf` 同路线。
- **GIG 暂缓**：R 的 `pGIG` 有 bug（`integrate(..., mu = 1, ...)` 写死 mu=1）；
  且密度需要 `besselK(1/sigma^2, nu)`，**JAX 无可微 BesselK**，AD 路径无法成立，
  需要单独实现可微 BesselK。
- **LOGSHASH 暂缓**：`dLOGSHASH` 在参考环境 gamlss.dist **6.1.1** 中不存在
  （只在 vendored 6.1-8 源码里），无法 R 对照。
- EGB2 测试注意：`nu=0.1` → `df1=0.2`，`qf(0.02,.2,2)` 在 R 下溢为 0（-inf），
  scipy 给真实 ~1e-16；属 df<1 病理域，测试网格从 nu=0.5 起步。
- 效果：placeholder 符号 15 → 10（剩 GIG×5 + LOGSHASH×5）。

## D1-E 批次三：LQNO 纠错 + MN3/MN4/MN5（commit 92c04df）

- **LQNO 参数化纠错（实质缺陷）**：Python 侧原本是三参数 tanh 分布，与 R 毫无关系；
  R 的 `LQNO` 是两参数族 `Normal(mu, sqrt(mu*(1+sigma*mu)))`，log/log 链接。
  `parameters` 由 `(mu, sigma, nu)` 改为 `(mu, sigma)`。
- 新内核模块 `omnilss/src/omnilss/dpqr_batch_f.py`（LQNO + MN3/4/5）；
  MN 的 AD `log_pdf` 委托给 `dMN*` 保证梯度与 `d` 不漂移。
- 新登记 R 缺陷：`qMN3/qMN4/qMN5` 完全忽略 `lower.tail` 与 `log.p`；
  `qLQNO` 则会处理 `log.p`（`if(log.p) p<-exp(p)`），两侧一致。
- 修复 `test_r_consistency_lqno.py`：旧版把 `nu` 传给 R（`unused argument`）且用负 `mu`。
- 新增 `tests/test_dpqr_batch_f.py`（21 项）；离散族的 q 验收用广义反函数条件
  `p(q(u)) >= u > p(q(u)-1)`（CDF 是阶梯函数，`q∘p=id` 不成立）。
- **环境结论**：参考 R 是**已安装的 gamlss.dist 6.1.1**（D0.5 门禁实测 `pinned`）；
  vendored `R/` 是 6.1-8 上游源码，仅作参考。`dDPO1`/`dLOGSHASH`/`dLOGSHASHo`
  在 6.1.1 中不存在 → `test_r_consistency_dpo1/logshash/logshasho` 等 8 个失败
  是既有 R 侧环境缺口，不是回归。
- 效果：placeholder 符号 35 → 15；队列剩 GIG / exGAUS / EGB2 / LOGSHASH。

## D1-E 批次二：PE2 / NOF / GAF 的 d/p/q/r（commit 563b9c3）

- 在 `omnilss/src/omnilss/dpqr_batch_e.py` 追加三族的核函数：
  - PE2：`z=(x-mu)/sigma`、`s=|z|^nu`、`cdf=0.5*(1+P(1/nu,s)*sign(z))`，
    并补上 R 的 `nu>10000` 均匀极限分支；q 走 `qgamma`（JAX 无不完全 gamma 逆，
    走 scipy `gammaincinv`，与既有 BCPE 做法一致）。
  - NOF：`sigma1 = sigma*|mu|^(nu/2)`，`N(mu, sigma1)`。
  - GAF：`sigma1 = sigma*mu^(nu/2-1)`，`Gamma(shape=1/sigma1^2, scale=mu*sigma1^2)`。
- **重要**：NOF/GAF 从二参数扩成三参数（R 的 `NOF`/`GAF` 本来就是三参数族，
  之前漏了 `nu`，等价于把 R 的默认值 `nu=0`/`nu=2` 写死）。`nu` 默认值沿用 R，
  退化点行为不变。链接：NOF(mu identity/sigma log/nu identity)、
  GAF(mu log/sigma log/nu identity)、PE2(mu identity/sigma log/nu log)。
- PE2 的 `_pe2_log_pdf` 去掉 `nu∈[eps,10]` 裁剪（会把 nu>10 的密度算错），改为委托 `dPE2`。
- 新增两条 R 缺陷登记（写进 `dpqr_batch_e.R_QUIRKS`，测试里有清单一致性断言）：
  - `qNOF` 没把 `log.p` 传给 `qnorm`（实测：R 两种取值返回完全相同的值）；
  - `dGAF` 在 `log` 分支之后才做 `ifelse(x<=0, 0, fy)`，log 密度返回 0（我们返回 `-inf`）。
- 效果：placeholder 符号 50 → 35；placeholder 族队列 11 → 8
  （剩 GIG/EXGAUS/EGB2/LOGSHASH/LQNO/MN3/MN4/MN5）。
