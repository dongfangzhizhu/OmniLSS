## D2.197 gamlss ri() / gamlss.ri 与 random() / gamlss.random（3 个符号）

- 新增 `ridge_random.py`：
  - `ri()`（R 的 ridge / Lp 平滑项规格）：`scale()` 标准化、`D=I`（order=0）或差分罚、
    `lambda<0→0`、`df` 越界→p/0，warning 文本照 R。**R 自己的 `ri()` 要求至少给 df 或 lambda**
    （两者都缺直接 stop）——所以 R 里 ML/GAIC 分支其实只在手工构造对象时才可达。
  - `gamlss_ri()`：复刻 R 的迭代加权 SVD：`RD=[R; sqrt(lambda)*sqrt(omega)*D]`，
    `omega=1/(|beta|^(2-Lp)+kappa^2)` 每轮刷新、`c.crit` 判停、edf=`sum(U1^2)`、`nl.df=edf-1`。
    lambda 四条路径：给定 / df 反解（`uniroot [0,1e5]`）/ ML 定点（20 轮，相对 1e-4 停）/ GAIC（有界优化）。
  - `random_spec()` / `gamlss_random()`：因子随机截距，`beta_k=sum(wy)/(n_k+lambda)`、
    `edf=sum(n_k/(n_k+lambda))`（只算出现过的水平）、`var=w/(n_k+lambda)`、`nl.df=edf`；
    df 路径用 R 的 `df.inv` 迭代（10 步、相对 1e-4）。
- 活 R 校验（R 端手工构造 tagged object 再调 `gamlss.ri` / `gamlss.random`，绕开 sys.calls 依赖）：
  fixed lambda / df 目标 / Lp=1 的 coef/fv/var 差 ≤4.6e-11、edf 1e-12 内一致；
  ML 定点 lambda 差 3.4e-16；GAIC（scipy L-BFGS-B vs R 的 PORT nlminb）lambda 差 1.2e-5；
  random 三条路径（ML / 固定 lambda / df）≤7e-17。
- 已知差异：order>0 时 ML 定点停在 R 的 1e-4 绝对容差，最后几位随停止轮次变化（lambda 相对差 1e-3、
  但 edf/coef 差 <2e-3）；random 的 xeval 分支依赖 R 的 predict 环境（按水平取历史拟合值），
  未移植，抛 `NotImplementedError`。
- 测试：新增 `test_ridge_random.py` 16 例（含 1 个 slow 活 R 对比，7 个 case 全覆盖）。

## D2.198 gamlss pp() / gamlss.pp 幂多项式 + scs()（3 个符号）

- 新增 `powerpoly.py`：
  - `pp()`：复刻 R 的 `fp.scale`（含非正值时 `shift = 最小正间隔 - min(x)`，注意不是「平移成正数」；
    scale = `10^(sign(log10 range)*trunc(|log10 range|))`），再 `(x+shift)/scale`；start 必须 1/2/3 个幂。
  - `gamlss_pp`：R 用 `nls(..., algorithm="plinear")`（Golub-Pereyra：幂做 GN、线性系数 profile 掉），
    Python 用 scipy `least_squares` 解同一个 profile 残差。
  - `scs()`：cs() 的变体（df/spar 转发给 gamlss.cs + 记录 NA），返回 name="scs" 的 CSSpline；
    与 cs 的 df 分支结果逐位相同（同一个 gamlss_cs 核）。
- **R 的 bug 照抄**：`gamlss.pp` 的 npoly=3 分支第二项写成 `coef[5]`（应为 `coef[6]`，powerpoly.R:88），
  R 的 `fitted.values` 因此与自己的系数不自洽。Python 同样用 `coef[4]`（0 基）复现，测试显式断言
  「fv == R 的错误表达式」且「fv 与正确线性组合差 >1e-3」。
- 活 R 校验（npoly=1/2/3）：`attr(values)` 完全相等；coef 差 ≤5.0e-5、fv 差 ≤7.6e-7（= nls 的 1e-6 相对容差）；
  nl.df 2/4/6 一致。
- 坑：R 的 nls 在 npoly=3 下极不稳（多组起点直接 `minFactor`/QR 报错）——**先探出能收敛的样本+起点再对照**，
  否则整个 R 脚本挂在 `pp` 外的 try 上。
- 覆盖：missing **251 → 248**，matched 829 → 832。
