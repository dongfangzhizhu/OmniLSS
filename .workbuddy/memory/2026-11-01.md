## D2.131a 交付：`mu/sigma/nu/tau.start` 用户入口

### R 语义（先查源码，不猜）
`gamlss-5.R`：`mu.start` 标量 → `rep(x, N)`（:1028），向量原样用；尺度是**参数尺度**
（与 `family$mu.initial` 同一尺度，`eta = mu.linkfun(mu)`，见 :431）。四个参数同构：
sigma :1061、nu :1095、tau :1129。`mu.fix` 等在 :996 只做 logical 校验。

### 实现
- `_fitting_init._resolve_start_values(family, start_values, n_obs)`：未知参数名 / 家族固定参数 /
  长度非 1 或 n / 非有限值 全部 ValueError（R 不前置校验，会在密度里炸，报错更难懂）。
- `gamlss(mu_start=, sigma_start=, nu_start=, tau_start=)` → `start_values` dict →
  `rs_fit` / `cg_fit_v2` / `mixed_fit`（mixed 只喂 RS 阶段，CG 阶段继承状态，与 R 相同）。
- RS 的 mu 分支：`eta_target = linkfun(start)` 逐观测交给第一内层步（与 family$mu.initial 同待遇），
  系数只做 WLS 记账。CG 的 mu/sigma/nu 分支同样先 linkfun 再 lstsq。
- `RS_JAX` / `HYBRID` / CG 的 `full_hessian` 后端没有等价状态交接 → 显式 ValueError。

### 验收
`omnilss/tests/test_start_values_r_parity.py` 12 passed。golden：
`omnilss/tests/fixtures/r_golden/family_start_values_2026-11-01.json`（`tmp/d2131_parity.R` 生成）。
**关键在制度选择**：必须用 `n.cyc=1 + i.control=glim.control(cyc=1)`，否则默认内层预算把所有
起点都拉到同一最优点、特性不可观测（第一次用 n.cyc=1 时 R 的 6 组结果完全相同，就是这个坑）。
对照数字：sigma.start=0.3 → dev 24.006637（R 同值）；GA 双起点 35.597522（R 同值）。

### 新发现（记为 D2.135）
NO/GA 的**默认** sigma 起点与 R 不一致：R 的 `NO()$sigma.initial = sd(y)`（本例 2.467793）、
`GA()$sigma.initial = rep(1)`；我们走通用残差尺度，而通用 mu 又落 `target=y` →
`RMSE(y,y)=0` → eps 地板 1e-6。单步制度下 deviance 差 1e2~1e11，50 周期收敛后一致
（所以三闸是绿的）。属既有缺陷（D2.51 同型陷阱），本轮不动绿族默认起点。


## D2.131b 交付：`mu/sigma/nu/tau.fix`

- R 语义：没有独立“固定参数”路径，`mu.fix=TRUE` 只是跳过 mu 子模型（`gamlss-5.R:310`），

## D2.134 交付：分类协变量 + `contrasts`（RS 路径）

- 审计结论修正：不是"加参数"，拟合路径此前**完全不支持分类协变量** ——
  `factor(g)` 报 "references variable 'factor'"，字符列 `g` 报 "could not convert string to float"。
- 实现：`_build_design_matrix` 识别 `factor(g)` 与非数值列，展开 k-1 列；编码
  `contr.treatment`（默认）/ `contr.sum` / `contr.helmert`，支持字符串或 {变量: 编码} 映射；
  `_ALLOWED_FORMULA_FUNCTIONS` 加 `factor`；单水平因子、未知编码 fail-closed。
- 验收：三种编码的 mu 系数与活 R 差 ≤3e-15，deviance 三编码逐位相同（-0.87162）。
- 范围：只接 RS；预测/newdata 重建还没带编码（登记 D2.136）。
- 坑：R 的 `contrasts="contr.sum"` 传裸字符串**不生效**（系数与 treatment 相同）；
  必须 `contrasts=list(g="contr.sum")`。第一次取对照数就被这个骗过。
