## D2.44：SICHEL / ZISICHEL / ZASICHEL 转录 R 闭式 score/hessian，撤掉 Bessel-JVP 评分缺陷

- **根因**：`bessel.py::_log_bessel_kv_jvp` 用渐近切线 `-1 - nu/(x+|nu|+1)` 替代真实 `d/dx log K_nu = -(K_{nu+1}/K_nu) - nu/x`，且完全丢掉 nu 切线。primal 精确（scipy）→ 密度对、AD 评分全错。gate 2 实测 SICHEL mu 9.3e-01 / sigma 1.2e+00 / nu 6.3e-01 rel；ZISICHEL 6.1e-01/7.9e-01/6.3e-01；ZASICHEL 5.5e-01/1.1e+00/1.3e+00。**不修公共 JVP**（会同时移动 GIG/SI 等所有 Bessel 族，另立任务），按 D2.40/D2.42 模式装族级 score_overrides/hessian_overrides。
- **gamlss 的 numeric.deriv 是前向差分**（已测：`ND(exp(nu), "nu", delta=0.001)` = `(f(nu+0.001)-f(nu))/0.001` 到 4e-14；与中心差显著不同 5e-4 rel）。注意它按名重求值调用帧表达式：`ND(exp(0.0), "nu", ...)` 直接报 `object 'nu' not found`——变量名必须先绑定。dldv 一律按前向差复刻。
- **R 的 clamp 方向**：`ifelse(d2ldX2 < -1e-15, d2ldX2, -1e-15)` 是保留更负者 = `minimum(-s², -1e-15)`（写 `maximum` 是反的，我第一版测试就踩了）。
- **ZASICHEL 唯一例外**：`d2ldt2 = -1/(tau(1-tau))`（非 -dldt²）；ZISICHEL 的 d2ldt2 仍是 -dldt²。ZASICHEL dldd/d2ldd2 先 floor sigma 1e-6；dldm 无此 floor。
- **槽位实测吻合**（vs R digits=17）：mu ≤4.2e-14、sigma ≤1.1e-12、tau ≤1.6e-14、nu ≤7.6e-8（前向差被 2/delta=2000 放大的跨库噪声）。
- **门禁**：`rs_family_parity_scan --families SICHEL,ZISICHEL,ZASICHEL` → deriv 3/3 pass、dpqr 3/3 pass、**rsdev 3/3 skip**。skip 原因是 **R 自己**报 `NA/NaN/Inf in foreign function call (arg 5)`（实测 R 在干净样本上 SICHEL dev=128.2298、ZASICHEL dev=93.3715 可拟合，ZISICHEL 在零多样本上 R 自己挂）。
- **性能缺陷（D2.45 候选，已实测）**：`_sichel_log_pdf` 与 `tofySICHEL` 都是 `lax.scan` 固定 100000 步（掩码但全跑），单次槽调用 0.3~0.9s → 一个 IRLS 周期数秒、200 周期 10~20 分钟。批量测试只构造族从不拟合，所以从未暴露。修法有现成范式：`dpqr_functions.py` 7454/7547 已用 `lax.while_loop` 动态上界。修完才能做 SICHEL/ZASICHEL 端到端拟合 parity。
- **DBURR12 是另一个分布（D2.45 候选）**：离散 Burr XII，`Sur(y)=(1+(y/mu)^sigma)^(-nu)`，要求 nu>0、nu.link=log、初值 sigma=nu=2；registry 目前把它别名到 SICHEL 内核（整体错）。dpqr gate 因 R 拒绝负 nu 校准网格而 skip —— 错误密度从未被对照。
- **回归**：SICHEL 族 13 个测试文件 118 passed（无 F/E/s）；新测试文件 45 例全绿（121s）；覆盖工件再生 ratchet OK（0 回归 / 18 改善）。

## D2.47：修复 log-Bessel JVP 根因（SI/GIG/PIG 等评分转正）

- **旧规则**：`_log_bessel_kv_jvp` 用 `-1 - nu/(x+|nu|+1)` 替代真导数且丢掉 nu 切线；`_log_bessel_iv_jvp` 同病。primal 精确 → 密度对、AD 评分全错。
- **新规则**：`d/dx log K_ν = -K_{ν+1}/K_ν + ν/x`（K 递推 `K_{ν-1}-K_{ν+1}=-(2ν/x)K_ν`，**I 是 +、K 是 −，符号相反**）；`d/dx log I_ν = I_{ν+1}/I_ν + ν/x`；`d/dν` 无闭式 → 对精确 primal 做中心差 h=1e-5（`_ORDER_TANGENT_STEP`）。第一次写成 `-ratio - ν/x`，被 ν=-0.5 的解析解（−1.5 vs −0.5）当场揭穿。
- **验证（三重独立参考）**：①Richardson 外推的 scipy primal 差分：dx ≤3.6e-11、dν ≤3e-9；②半整数闭式 `K_{±1/2}`、`I_{1/2}` 到 1e-12，二阶 `d²/dx² logK_{1/2}=1/(2x²)` 精确；③活 R 的 SICHEL 闭式槽位：**AD 评分（不用 overrides）dldm ≤7.8e-14、dldd ≤1.3e-12**。dldv 与 R 差 5.5e-3~1.0e-2 是 R 前向差自己的误差（我们中心差 vs 真值 ≤2.9e-6）。
- **门禁**：12 个 Bessel 族 gate2 全 pass（SICHEL/ZISICHEL/ZASICHEL/SI/GIG/PIG/ZIPIG/ZAPIG/DEL/DELAPORT/ZINBI/ZANBI）+ 对照 NO/TF/BCCG pass。SI 6.42e-01→pass；GIG 4.98e-01→pass。**PIG 三闸全 pass（rsdev 219.393 vs R 219.393）**。
- **仍失败（既有，stash 对照确认非本改）**：GIG dpqr（d rel 8.1e-2、p/q 无有限交集 = placeholder 的 nan 占位）；GIG rsdev（placeholder 拒绝）；`test_pig_api::test_boundaries_and_limits`（pPIG(10001)=1.0 vs 期望 NaN）；`test_dpqr_comprehensive::test_NBII_r/_consistency`（r 返回 None）。测试跑出的 `Rplots.pdf` 已删。
- **回归**：347 pass / 14 skip / 2 fail（NBII 既有）。
- **待办（登记数字失效）**：ZIPIG/ZINBI 在 `_RSDEV_R_STOPPED_EARLY` 的登记数字建立在旧评分上，JVP 修正后轨迹改变 → 需**全族流**扫描重立（子集扫描因共享 rng 移位不可用）。全族扫描已启动（本次会话内 105/146）。
