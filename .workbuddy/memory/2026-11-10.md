## D2.219 gamlss.ggplots::y_ecdf 非参数 ECDF 置信带（1 个符号）

- 新增 `ecdf_bands.py`：`y_ecdf` 返回 `(EcdfBand, EcdfData)` —— 即 R 里
  `geom_ribbon`（Owen / Jager-Wellner 同时置信带）与 `stat_ecdf`（ECDF 表）
  背后的数值数据，不绘图。`missing` **184 → 183**，matched 896 → 897。
- **数值核（活 R 对照 10 组，全部 ≤1.6e-15）**：
  - `NPOwen.bands` / `NPJagerWellner.bands`（Ross Darnell SMIR）：在 distinct
    值上 `p = cumsum(table)/(n+1)`，按 `log(nn)` 多项式算 `lambda`（95/99 各一套、
    n<=100 与 n>100 分支不同），`lambda = sqrt(2·lambda)`，
    `phi = pbeta(p,1/3,1/3)`，`se = 1/(5.3·sqrt(nn·(p(1-p))^(1/3)))`，
    `[lower,upper] = qbeta(clip(phi ∓ lambda·se,0,1),1/3,1/3)`。
    scipy `beta.cdf/ppf` 精确对应 R `pbeta/qbeta`。
  - **R 源码坑（如实复刻，不修）**：99%-Owen 的 lambda 多项式在小 n 为**负**，
    `sqrt(2·lambda)` → NaN → 整条带全 NaN（R 运行时报 `NaNs produced`）。
    测试 `test_owen99_band_is_all_nan_like_r` 钉住 NaN 模式一致。
  - `gamlss::ECDF` 分母是 **n+1 不是 n**（如 `ECDF(c(1,2,2,3))(观测)` =
    c(0.2,0.6,0.6,0.8)），并列值取相同分数；写成 n 会全错。
  - `other_prep_data` 按观测位置丢 NA、用 `median ± value·IQR`（type-7 分位数）
    着色离群点；**bands 基于去 NA 后的 `d$y`**（不是原始含 NA 向量）——
    首版踩到（含 NA 时 `np.unique` 多算一个 NaN，形状不符），已修。
- **探针门禁**：`ECDF` 在 gamlss namespace 不在 globalenv，探针要显式
  `ECDF <- gamlss::ECDF`（真实函数体）；`ggplot(...) + geom_*()` 需全局
  `Ops.ggstub`；`geom_ribbon`/`stat_ecdf` 做成 recorder 捕获 data.frame。
