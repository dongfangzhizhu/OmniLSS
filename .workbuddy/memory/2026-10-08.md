## D2.23（提交 `b0d1bee`）：DBI 双参数似然

`DBI` 从 `BI` 转发壳（`parameters == ("mu",)`）变成 Borg 1988 双参数族。
扫描器三关从 `skip fail pass` 变`pass pass pass`。

**族侧**：新增 `omnilss/src/omnilss/distributions_dbi.py`（~420 行），删除
`distributions_count_compat.py`（整个文件只有 DBI 的转发壳）。核心是
`C(mu, sigma, bd)` 的逐字转写（`getBI_C2.c`，65 行有限和）+ `_dbi_log_pdf`
（含 `|sigma-1| < 0.001` 的 `dbinom` 分支）+ `_dbi_cdf` / `_dbi_quantile`
（`pDBI` / `qDBI`，族上未挂但函数真实）+ R 的 Fisher scoring Hessian。

**五个根因**（详见 commit message）：
1. `C` 是有限求和不是积分，三个闭式猜测全错；误判线索是**对称探针网格**
   掩盖了 `mu` 依赖性。
2. `GetBI_C` 先做 `sigma <- 1/sigma`。
3. `dDBI` 在 `|sigma-1| < 0.001` 切到纯 `dbinom`。
4. **工具侧**：形状判据只看 `bd` →标量 `bd` + 向量参数时 squeeze 抛异常 →
   `calibrate` 返回 `ok=False` → **静默 `deriv: skip`**。
5. **工具侧**：`_DERIV_TOLERANCE` 缺 `("DBI","sigma")` 登记。根因 4 修好后
   `deriv` 变 `fail`，唯一失配点是 `sigma=1.0` —— 恰在根因 3 的窗口内。
   活 R 求证证明**R 自己不一致**（窗口内 R 密度的中心差分给 0，R 的 `dldd`
   给 -0.48）；我们逐位抄 R，登记容差 + 证据，不改代码。

## D2.24：把"停在非驻点"变成可观测的量（承接上面候选 1）

### 现象

全族扫描 v14：`BCPE  deriv pass / dpqr pass / rsdev fail`，
我们 `94.1536` vs R `122.8256`（rel 2.334e-01），方向是**我们更低**。

### 判定被推翻了两次

**第一次（错）**：结论写成"两个数值上不连通的盆地"，证据是固定 `nu`/`tau`
时 `sigma < 1.1077`（含 R 的 0.508149）返回 `Inf`，两侧皆然。

**错因**：那个切片取在**我们自己仍未收敛的迭代点**上。`tau` 从 17631 爬到
473368 时，同一个 `sigma` 阈值跟着变。**切片量的是算法走过的路，不是地形。**

**第二次（对）**：R 在 gate 真正比较的那份48 观测样本上，`n.cyc` 20/30/100/
300/1000 全部返回同一个 `122.825553739168` 且报 `converged = TRUE`；逐迭代
最后一步变化 0.0006 < `c_crit = 0.001`。而在 **R 自己的最优点**上：

```
dldm = -2.1556e+01    sum(dldm * x) = -4.1895
sigma * dldd = -4.8000e+01           dldv = -8.2223
tau * dldt   = -3.8259e-09
```

我们 `n_cyc=20` 是 94.153575（`max_iterations_reached`），`n_cyc=40` 到
**94.115024891890840**；R 自己的 `dBCPE` 在该系数上给 `94.115024891890670`
（差 1.7e-13）。**两侧的 `converged` 都不是在报告最优性。**

### 交付

`rs_algorithm.eta_gradient_norms()` → `model` 的 `eta_gradient_norm` /
`eta_gradient_norm_by_param` 槽位。需要链式法则的 `dmu/deta`：natural 尺度
`dld` 跨参数不可比（BCPE 的 `sigma`/`tau` 是 log 链而 `nu` 是 identity）。

**这个量刻意不 gate `converged`** —— 见下。

### 被自己的判据推翻的阈值

第一版是 gate 的：`eta_grad > 1e-3` 就清 `converged` 并发新终止原因
`stalled_at_nonzero_gradient`。阈值来自"正常族 8.3e-14~9.4e-05 vs 卡住的族
1.0 / 1.6e+09"这个看着干净的分离。用"沿梯度走一步能不能真降 deviance"一测，
**分离是假的**：

| 族 | `eta_grad` | Fisher 步增益 | |
|---|---|---|---|
| `PO` | 1.6e-03 | 1.9e-08 | 假阳性 |
| `WEI2` | 1.2e-02 | 2.9e-06 | 命中 |
| `GG` | 2.6e-01 | 8.1e-05 | 命中 |
| `LOGITNO` | 2.5e+00 | 9.1e-13 | 假阳性 |
| `BCPE` | 1.16e+00 | 9.0e-03 | 命中 |
| `LNO` | 8.8e+12 | 4.3e+12 | 命中 |

`PO` 与 `WEI2` **重叠七倍** → 任何阈值都分不开。gate 版本会把已收敛的
Poisson 拟合误标成停滞。**量级分离不是判据，"走一步能否下降"才是**（与
D2.19 的参数地板判据同构）。

### 又踩了一次"错的复现脚本"

`g_dev_inc` **已经是完整 deviance**（`rs_algorithm` 里是
`g_dev = sum(w * g_dev_incr)`，没有 ×2）。探针里按 `-2*logL` 的反射乘了 2，
让 `7.6e-16` 的 Newton 步看起来把 deviance 移动了 168 —— 据此得出过
"`stalled` 判定全错"的**反向**结论。D2.23 第 5 条在新场景下重现。
