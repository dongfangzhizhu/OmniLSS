## D2.215 gamlss.ggplots 二维中位数 / 2-D ECDF（5 个符号）

- 新增 `copula_medians.py`：`median_cw` / `median_pc` / `median_sp` / `xy_median` / `ECDF_2D`，
  R 源 `R/gamlss.ggplots/R/Copula_ralated.R`。`missing` **209 → 204**，matched 871 → 876。
- **照抄的 R 坑（都写进 docstring + 测试）**：
  - `median_pc` 算了 `gamlss.foreach::getSVD` / `beta_coef` / `fv`（还有 `++beta_coef` 双正号），
    但最后 `out <- c(median(x), median(y))` **覆盖** → 全部是死代码，返回值就是边际中位数；
  - `xy_median(method="cw")` **错调 `median_pc`**（不是 `median_cw`）；因为死代码两者数值相同，
    用 monkeypatch 计数钉住调用链；
  - `y` 没有默认值 → R 不显式传 `y=NULL` 时 2 列矩阵分支**不可达**，报
    `"argument \"y\" is missing, with no default"`；Python 按意图支持 `y=None`，记录差异；
  - `ECDF_2D` 标量语义：向量 value 会被 R recycle（带 warning），`mean()` 仍返回**一个标量**；
    Python 用 `np.resize` 复现回收，不擅自向量化。
- **活 R 对照**：`gamlss.foreach` 未安装（会报 `there is no package called`），但 `median_pc` 的
  `getSVD` 结果被覆盖 → 用文本替换桩让 R 函数跑通是安全的；已在探针与测试 docstring 说明。
- **`median_sp` 的 R 提前停判定（parity 五判据第 2 条）**：R `optim` 默认 `reltol≈1.49e-8`
  停在 `[6.812418, 5.449416]`，比真解差 **3.4e-4**；R 收紧到 `reltol=1e-14` 得
  `[6.812074, 5.449337]`。Python 用 scipy Nelder-Mead 严格容差落在真解（与 R tight 差 **4.8e-7**）。
  两步判定齐全：`fn(ours) = 39.213436850822475` ≤ `fn(R_default) = 39.213436906487864`，
  且 = `fn(R_tight)`（1e-10）。其余 12 组（cw/pc/xy_*/矩阵形式/第二组数据/ECDF）**误差 0**。
