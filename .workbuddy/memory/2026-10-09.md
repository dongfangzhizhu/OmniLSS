## D2.26：`ZIPIG` 的 `nu` 初值 —— 加预算反而更差（rsdev fail → R 提前停）

### 现象

D2.25 修完元数据后新暴露的（gate 用 20 步）：

```
n_cyc= 20  dev= 455.25873594  conv=False  max_iterations_reached
n_cyc= 60  dev= 214.64580000  conv=False  max_iterations_reached
n_cyc=200  dev= 732.78835534  conv=False  max_iterations_reached   <- 加预算反而更差
```

`mu` 前 5 位在所有预算下一致（`1.3452 / -0.0971`），`sigma` 在 link 尺度上
剧烈震荡（`-25.9 → +253.0 → -191.3 → -290.3 → -335.4`）。
逐迭代 trace 是**周期 4 的极限环**：

```
iter  1-18:  3251.14 → 214.6458   单调下降
iter 19:      214.6458 → 788.22
iter 20-22:   455.26 → 816.69 → 1450.21
iter 23-30:   1408.86 → 1373.58 → ...  与 iter 2-9 逐位相同
```

### 根因

**`ZIPIG` 在 `_initial_parameter_value` 的每一个分支里都不存在** → 落到
兜底 `return 1.0`。`nu` 是 logit 链，`logit(1.0) = +inf` → 被 eta clip 截成
`+15`；R 的 `ZIPIG.R:91` 是 `nu <- rep(0.1, length(y))` → `logit(0.1) = -2.197`。
**起点差 17 个 logit 单位。**

从错误起点出发落进一片 `sigma` plateau，**宽达三个数量级**（两侧独立测得，
各自一位不变）：

| `sigma` | 我们 | R |
|---|---|---|
| `1e-146 … 5e-12` | 214.6458023279 | 210.0586991363 |
| `1e-3` | 214.6437800339 | 210.0261110504 |
| `0.0821` | 215.7554497851 | **209.0949097249**（切片最低） |

**plateau 地板比 R 的落点高 2.86** → 真正错的是 `mu`/`nu`，`sigma` 只是
被连带困住。

### 修法

补七个族（`nu` **就是**零点质量的那些）：`ZIPIG`/`ZAPIG`/`ZIBI`/`ZAZIPF`/
`ZABI`/`ZANBI`/`ZINBI` → `0.1`。

**名单为什么这么窄**：`nu` 名字相同、角色不同。第一版把 `ZABNB`/`ZIBNB`/
`ZINBF`/`ZISICHEL`/`ZASICHEL` 也塞进 0.1，实测 `ZINBF` 的 `nu`（R=**2**）
会被改成 0.1。`ZASICHEL`/`ZISICHEL` 的零点在 `tau`（Sichel 底座已有 `nu`），
R 给 `nu` = **-0.5**。**同名不同义，D2.19 的老教训。**

### 顺手查清并否定的两个候选

- **R 的 kernel 开关** `dZIPIG`：`fy[sigma>0.0001] <- dPIG` /
  `fy[sigma<=0.0001] <- dPO`。实测 `dPIG(0, mu=4, sigma)` 在 `sigma→0` 时
  **平滑收敛到 `exp(-mu)`**（`sigma=1e-5` 给 `-3.99992000`），切换点 `1e-4`
  处两核只差 `1.5e-5`。**不是根因。** 我第一版凭 `1/sqrt(1+2σμ)` 猜它趋近 1，
  猜错了。
- **`rs_algorithm.py` 的 `max(sigma, 1e-6)` 地板**：确实存在，但 `sigma`
  在 `1e-6 … 1e-3` 全在 plateau 内，**地板不是原因**，只是恰好落在里面。

### 方法论

1. **"加预算反而更差"是发散的签名，也是最强的线索**。`455 → 214 → 733`
   一眼排除"收敛慢"。非单调 = 两个吸引子间摆动，入口通常是**初值**或
   **步长**，不是密度。
2. **同名不同义（第二度）**：D2.19 说"grep `nu.link` 命中 4 个族只有 1 个
   是 log"；D2.26 说"叫 `nu` 的参数有三种角色——零点质量/形状/底座自带"。
   **按名字分组一定出错，必须按角色分组。**
3. **兜底默认值不是安全的默认值**。`return 1.0` 对 logit 链意味着 `+inf`。
   对一个"漏了就静默"的分支，正确做法是让它**响**。
4. **修正错误的 monkey-patch 与"假设被否证"输出完全相同**。第一次 patch
   打在 `_fitting_init` 模块属性上，而 `rs_fit` 是 `from ._fitting_init import`，
   补丁没生效——两次运行**连震荡的 `sigma_eta = -191.26320429` 都一位不差**。
   **"改了但没生效"与"假设不成立"长得一模一样。**
5. **R 也有不收敛到自己最优的场合，而且可以量化**。`ZIPIG` 的 R 轨迹
   **单调上升**——它是"停下"而非"到顶"。
