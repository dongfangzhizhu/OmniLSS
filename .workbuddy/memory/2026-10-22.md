## D2.52：LOGSHASH 整族交付（批次内最后一个 placeholder → 0）与 SHASH 求逆内核加固

- **LOGSHASH = SHASH 的 log 变换**：R 的开发版源码（R/gamlss.dist/R/LOGSHASH.R，Mikis 15-07-2025）把全家定义为 dLOGSHASH(x)=dSHASH(log(x))/x、p/q 同理、十个 score 槽全是 SHASH()$slot(log(y),...)。**安装版 gamlss.dist 6.1.1 没有这个族**（实测 exports 无 LOGSHASH/LOGSHASHo，连 R 源文件都不在）——所以没有活 R 直接对照，但 SHASH 在安装版里，于是每个契约都能对**活 R 的 SHASH 在变换后参数上**验：d/p/q 逐值 digits=17 比对；端到端更有 G.dev_LOGSHASH(y) = G.dev_SHASH(log(y)) + 2*sum(log(y))（对数变换的雅可比是参数无关常数），拟合 parity 也可对活 R 验。
- **旧实现三处错**：①log 密度用了另一套（Jones-Pewsey 式 sinh((asinh(z)-nu)/tau)、无 log(c) 项）——自洽到能过 AD deriv 闸但不是 R 的分布；②links 是 mu=log/nu=identity（R：mu=identity、sigma/nu/tau=log）；③根本没有 d/p/q/r（nan 占位，PLACEHOLDER 被生产路由拒）。初值四项也全缺。修法：log 密度委托 dLOGSHASH（与公开 d 同一内核），d/p/q/r 全部 Transform 复用 SHASH 内核（结构上不可能漂移），初值按 vendored 表达式录入（mu=(log y+mean)/2、sigma=sd(log y)/5 n-1、nu=tau=0.5；族对象不在安装版 R，出处只能是 vendored，已在代码注释和工作日志记档）。
- **R 边界怪癖全部复刻**（赋值在 log/tail 变换之后，故 log 模式给 0 不给 -inf）：d 的 ft[x<=0]<-0、p 的 cdf[q<=0]<-0 与 cdf[q==Inf]<-1、q 的 p==0->0 与 p==1->Inf 与 p 越界->NaN；d/p/q 对 sigma/tau/nu<0 停 → 我们给 NaN（族对象 nu.valid=TRUE 是 R 自己的不一致，照录）。
- **qSHASH 求逆内核加固（连带修了 SHASH 自己的缺陷）**：旧求逆是 z 空间 Newton（导数带 1/sqrt(1+z^2)、步长 clip ±10），尾部导数塌缩 + clip 冻结迭代——实测 (mu=.3,sigma=.5,nu=.2,tau=1.5) p=0.01 处我们 -100.83 vs 活 R -544.79（rel 0.81）；p 距 1 的 1e-16 内直接 NaN（采样器 20000 个出 2 个 NaN）。改为 s=asinh(z) 空间括号二分（f(s)=0.5*(exp(tau*s)-exp(-nu*s))-r 严格单调，括号由渐近项给出：hi=log(2*max(r,0)+2)/tau、lo=-log(2*max(-r,0)+2)/nu，nu=0 时左极限 -0.5 走 log(1+2r)/tau 分支），90 步 JIT 安全。修后：对 R rel 4.2e-5（R uniroot 自身误差）、往返机器精度、尾部有限、采样器零 NaN。SHASH/SHASHo2/SHASHo 回归测试全绿，扫描器 SHASH dpqr/deriv 闸仍 pass。
- **一个探测参数域教训**：profile (mu=1.2, sigma=0.8, nu=0.05, tau=2.0) 下**活 R 自己的 qSHASH 不返回**（uniroot 区间扩张 while 不死循环），两侧都算不出——该 profile 从测试网格剔除并记录理由（D2.28 探测参数须落在可计算域的又一形态）。
- **拟合 parity（对活 R）**：同初值（R 的 LOGSHASH 初值就是 SHASH 初值作用在 log y 上）同预算 50 周期：我们 53.7826562140556 vs R 53.772077160882141（rel 1.97e-4，逐周期轨迹从第 1 轮起差 0.006 同盆地）。1000 周期两侧都收敛，我们更低（53.484156174299699 vs 53.522983976260143，rel 7.25e-4）——按我们更低两步裁定走第二步：**R 自己的 dSHASH 在我们收敛点上的取值逐位复现我们的 deviance**（53.484156174299699），即我们的点是 R 似然的真点、R 的 RS 停在劣质驻点（PE2 处置变体）。
- **placeholder 队列清零**：再生覆盖工件后 placeholder-migration-queue 显示 0（LOGSHASH 是批次内最后一个）；ratchet OK。旧 test_r_consistency_logshash.py 对不存在的 R 函数 SUBFAIL（既有失败），删除并由 test_logshash_parity.py（17 例：变换 d/p/q 对活 R、边界怪癖、初值、拟合 parity、R 密度自检）取代。
